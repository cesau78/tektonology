# Prayer Sole — v3 compound fastened
This folder contains the Tektonology Prayer Sole fastened system: a rigid PLA **collar** shell, a soft TPU **tread**, and a **cap**, assembled with mechanical fasteners (no glue required for the v3 fastener design).

### Print settings (Bambu A1)
* **Collar:** Polymaker PLA Pro (Black) | 4 Wall Loops | 35% Gyroid Infill.
* **Tread:** TPU 90A | 4 Wall Loops | 35% Gyroid Infill | Print Speed < 40mm/s.
