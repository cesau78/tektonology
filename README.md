# tektonology

A church maintenance system in progress: help parishes organize parishioners around upkeep and restoration. 3D printing is central—anyone can contribute printable parts and fixtures—alongside web tools, data, and local agents.

## Principles and conventions

- **[heuristic-imperatives.md](heuristic-imperatives.md)** — how we weigh tradeoffs (suffering, prosperity, understanding). Canonical copy for humans and tooling.
- **[CLAUDE.md](CLAUDE.md)** — JSON shape, repo layout, Next.js static export, languages.
